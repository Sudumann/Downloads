Install help

Installing a download

Files from this page aren't from a store yet, so your device asks once before installing them.

Android (.apk)

  1. Tap Android on the app's card. Your browser may warn that the file can be harmful — choose Download anyway.
  2. Open the downloaded file from your notifications or the Files app.
  3. If asked, allow Install unknown apps for your browser or file manager, then go back and tap Install.
  4. When the Play Store version arrives, you can switch to it for automatic updates.

Windows (.exe)

  1. Click Windows on the app's card and run the installer when it finishes downloading.
  2. Installers are per-user and don't need administrator rights.
  3. If Windows SmartScreen appears, choose More info → Run anyway. This shows for new independent releases that haven't built up a reputation yet.
  4. Uninstall any time from Settings → Apps.
